# Gaming Statistics Dashboard

Responsive, dependency-free HTML/CSS/JavaScript dashboard with fictional match data. Displays win rate, K/D, accuracy, match history, game-mode filter, and win/loss charts using accessible HTML and SVG/CSS.

## Preview
Open `index.html` in a browser. No installation or backend needed.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → main / root. Your site will be available at `https://YOUR_USERNAME.github.io/Gaming-Statistics-Dashboard/` once deployed.

## Data
Edit `data/matches.json` to change fictional data. The app embeds the same sample matches in `app.js` for `file://` compatibility, so update both if customizing. No player accounts or external APIs are used.
